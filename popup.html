Pigeontab

"Merge windows" moves the tabs from all your windows into this one, joins groups that have the same name, then groups the tabs. "Close duplicates" keeps one copy of each page across all windows.

Pick a rule to add the site to it. The tabs are grouped again right away.

    Groups in this window

      No groups yet. Press Organize now.

      When on, a page that is not in any group goes to its rule group after it loads. Tabs already in a group are never moved.

      Rules

      A tab joins the first rule (from the top) whose word is part of the site name. "github" matches github.com and gist.github.com, but not githubstatus.com.

      With "Also match the tab title" on, a tab whose site matches no rule can join by a whole word in its title: "spring" matches "Spring Boot guide", but not "Springfield".

      Obsidian

      "Save to Obsidian" makes a note with a link to each tab in this folder. Chrome asks "Open Obsidian?" first; choose Open, and tick "Always allow" if Chrome offers it.

      Shortcuts: not set (change them at chrome://extensions/shortcuts)
